# Code of Conduct

pyne-agent-worker follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

## Our standards

- Be respectful and constructive.
- Assume good intent.
- No harassment, discrimination, or personal attacks.

## Reporting

Report unacceptable behavior to the maintainers. Replace this line with a
contact method before publishing the project.
